# G6 targeted pilot: known-hash holders against D4 and D5 (exploratory)

Generated by `scripts/g6_targeted_report.py`. Primary MAWI day, oracle gate, 20 victims per set (`top`: the 20 largest benign long flows; `vul`: the 20 largest that never reach 2,048 packets), holders start 0.5 s before the victim's first packet. Analytical attacker: it is *given* the slots it needs (no hash search, no probing model, no adaptive behaviour). Share of victims downgraded, mean over draws (clock starts) with a 95% percentile bootstrap interval; the no-attack column is the same design without holders.

Reading: with both hashes known, D4 asks the attacker for two holders per victim instead of one (a constant factor); with a secret second hash the attacker's second holder finds the victim's table-B slot only by chance. The pilot does not model probing that learns the second hash (about 20 to 35 refusal probes for a small keyed space, `docs/lit/overnight_adversary_model.md`), adaptive holders, or the both-ways-owned race of a real recirculation path. It supports no claim about a hash-knowing adversary beyond the constant factor.
