# G2a results: NetBeacon slot behaviour on MAWI, no attacker

Generated by `scripts/g2a_report.py` from `results/g2/a_*.npz`. First 120 s of the pre-registered days, 65,536 slots, NetBeacon's timeout. `model` = the shipped PeerRush-trained flow-size gate; `oracle` = a flow takes a slot iff it truly has more than 50 packets in the slice. MAWI has no application labels, so this measures slot contention, not accuracy. A packet is a *collision* when an active slot holder refuses its flow; an *empty-slot refusal* is the clock-wrap artefact (a never-used slot looks active for 268 ms after each 4.295 s wrap). 95% intervals are percentile bootstraps over draws.
